# conduktor_console_connector_template_v2

Resource for managing Conduktor Console connector templates.
This resource allows you to create, read, update and delete connector templates in Conduktor.

Connector templates allow platform teams to define reusable connector configurations with default
values and metadata, enabling application teams to quickly create connectors with pre-filled settings.

## Requirements

- Conduktor Console version `1.46.0` or later.
- Enterprise plan required.

## Example Usage

### Simple connector template
```terraform
resource "conduktor_console_connector_template_v2" "simple" {
  name = "simple-connector-template"
  spec = {
    display_name = "Simple Connector Template"
    description  = "A simple connector template for S3 sink connectors"
    defaults = {
      spec = {
        class = "io.confluent.connect.s3.S3SinkConnector"
        config = {
          "tasks.max" = "1"
          "s3.region" = "us-east-1"
        }
      }
    }
  }
}
```

### Complex connector template
```terraform
resource "conduktor_console_connector_template_v2" "complex" {
  name = "complex-connector-template"
  labels = {
    env    = "production"
    domain = "data-platform"
  }
  spec = {
    display_name = "Complex Connector Template"
    description  = "A complex connector template with metadata defaults"
    defaults = {
      metadata = {
        name = "{{team}}-{{connector_type}}-connector"
        labels = {
          managed-by = "terraform"
          team       = "{{team}}"
        }
      }
      spec = {
        class = "io.confluent.connect.s3.S3SinkConnector"
        config = {
          "tasks.max"            = "1"
          "s3.region"            = "us-east-1"
          "s3.bucket.name"       = "{{s3_bucket}}"
          "flush.size"           = "1000"
          "rotate.interval.ms"   = "3600000"
          "storage.class"        = "io.confluent.connect.s3.storage.S3Storage"
          "format.class"         = "io.confluent.connect.s3.format.avro.AvroFormat"
          "schema.compatibility" = "FULL"
        }
      }
    }
  }
}
```

## Import

In order to import a Connector Template into Conduktor, you need to know the Connector Template name.

For example, using an [`import` block](https://developer.hashicorp.com/terraform/language/import) :
```terraform
import {
  to = conduktor_console_connector_template_v2.example
  id = "my-connector-template"
}
```

Using the `terraform import` command:
```shell
terraform import conduktor_console_connector_template_v2.example my-connector-template
```
