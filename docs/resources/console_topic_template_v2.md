# conduktor_console_topic_template_v2

Resource for managing Conduktor topic templates.

Topic templates define reusable blueprints for Kafka topic creation — including default partitions, replication factor, configs, and a naming pattern with [Handlebars variable interpolation](https://docs.conduktor.io/guide/reference/console-reference) (e.g. `topic-{{department}}`).

Requires Conduktor Console >= `1.26.0` and an enterprise plan.

## Example Usage

### Simple topic template
```terraform
resource "conduktor_console_topic_template_v2" "simple" {
  name = "simple-template"
  spec = {
    display_name = "Simple Template"
    defaults = {
      spec = {
        partitions         = 3
        replication_factor = 1
        configs = {
          "retention.ms" = "604800000"
        }
      }
    }
  }
}
```

### Complex topic template
```terraform
resource "conduktor_console_topic_template_v2" "complex" {
  name = "complex-template"
  labels = {
    team = "platform"
    env  = "prod"
  }
  spec = {
    display_name = "Complex Production Template"
    description  = "High-throughput template for production services with Handlebars naming"
    defaults = {
      metadata = {
        name = "svc-{{department}}-{{env}}"
        labels = {
          managed-by = "terraform"
        }
      }
      spec = {
        partitions         = 12
        replication_factor = 3
        configs = {
          "retention.ms"        = "604800000"
          "cleanup.policy"      = "delete"
          "min.insync.replicas" = "2"
        }
      }
    }
  }
}
```
