# conduktor_gateway_group_v2

Resource for managing Conduktor Gateway groups.
Groups aggregate service accounts and/or external group names (LDAP, OIDC) for use in Gateway interceptor policies.

## Example Usage

### Simple group with no members
```terraform
resource "conduktor_gateway_group_v2" "simple_group" {
  name = "simple-group"
  spec = {}
}
```

### Group with external groups
```terraform
resource "conduktor_gateway_group_v2" "complex_group" {
  name = "complex-group"
  spec = {
    external_groups = ["ldap-admins"]
  }
}
```
